# BrailleFlow

เว็บแอปพลิเคชันท่อส่งข้อมูล (Data Pipeline) สำหรับแปลงเอกสารการเรียนรู้คุณภาพต่ำ
(ภาพสแกน / PDF หลายคอลัมน์) ให้กลายเป็นข้อมูลโครงสร้างสูงและไฟล์อักษรเบรลล์มาตรฐาน (.brf)

## โครงสร้างโปรเจกต์

```
brailleflow/
├── app.py                  # Streamlit UI หลัก (3 หน้าจอ)
├── modules/
│   ├── ingestion.py        # อัปโหลดไฟล์ + OCR สกัดข้อความ/พิกัด
│   ├── quality.py          # ตรวจสอบคุณภาพข้อมูล (noise, OOV, สระลอย)
│   ├── pipeline.py         # ทำความสะอาด + XY-Cut จัดลำดับ + สร้าง Document Tree
│   └── braille.py          # แปลงข้อความไทย -> จุดเบรลล์ -> ไฟล์ .brf
├── sample_data/
│   └── test_page.png       # ภาพเอกสารตัวอย่าง 2 คอลัมน์ (สร้างขึ้นเพื่อทดสอบระบบ)
├── requirements.txt
└── README.md
```

## การติดตั้ง (Setup)

โปรแกรมต้องการ Python 3.10+ และ Tesseract OCR (พร้อมชุดภาษาไทย) และ Poppler
(สำหรับแปลง PDF เป็นภาพ)

### 1. ติดตั้ง system dependencies (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-tha poppler-utils
```

บน macOS (ผ่าน Homebrew):

```bash
brew install tesseract tesseract-lang poppler
```

### 2. ติดตั้ง Python packages

```bash
cd brailleflow
pip install -r requirements.txt
```

### 3. รันแอปพลิเคชัน

```bash
streamlit run app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8501`

## วิธีใช้งาน (3 หน้าจอ)

1. **① นำเข้าเอกสาร (Ingestion)** — อัปโหลดไฟล์ PDF/รูปภาพ ระบบจะรัน OCR สกัดข้อความ
   พร้อมพิกัด bounding box ของทุกคำ
2. **② ตรวจสอบคุณภาพ & รัน Pipeline** — ดูรายงานคุณภาพข้อมูล (noise %, OOV, สระลอย)
   ภาพต้นฉบับพร้อมจุดที่ระบบตรวจพบปัญหา แล้วกด "Run Pipeline" เพื่อทำความสะอาด
   จัดลำดับการอ่านใหม่ (แก้ปัญหาหลายคอลัมน์) กรอง header/footer และแปลงเป็นโครงสร้าง
   JSON แบบลำดับชั้น (Document → Section → Paragraph) พร้อม Data Lineage
3. **③ พรีวิวเบรลล์ & ส่งออก** — แปลงข้อความที่จัดโครงสร้างแล้วเป็นจุดเบรลล์ไทย
   ดูตัวอย่างหน้าสัมผัสจำลอง (Tactile Grid) และดาวน์โหลดไฟล์ `.brf` หรือ `.json`

## ข้อจำกัดที่ทราบแล้ว (Known Limitations)

- **ความแม่นยำของ OCR** ขึ้นกับคุณภาพภาพต้นฉบับและโมเดลภาษาไทยของ Tesseract
  เอกสารที่มีฟอนต์แปลก/ความละเอียดต่ำมากอาจต้องปรับพารามิเตอร์ pre-processing เพิ่มเติม
- **ตารางแปลงเบรลล์** (`modules/braille.py`) ครอบคลุมพยัญชนะ สระหลัก วรรณยุกต์
  และตัวเลขที่ใช้บ่อย แต่ยังไม่ครบทุกกรณีของสระประสม/อักษรควบซับซ้อน — เหมาะสำหรับ
  สาธิตแนวทางทางวิศวกรรมข้อมูล (text → dot pattern → BRF) ไม่ใช่โปรแกรมที่ผ่านการ
  รับรองมาตรฐานสำหรับผลิตสื่อจริง ตามที่ระบุไว้ในหัวข้อ 5 ของเอกสารโครงงานว่าการคำนวณ
  จัดหน้าเบรลล์ที่สมบูรณ์ (ตัดคำ/จัดหน้า 2 มิติแบบไม่ตกหล่น) จะอยู่ในโมดูล AI/CSP
  ที่เชื่อมต่อเพิ่มเติมในอนาคต
- การแบ่ง Section/Paragraph ใช้กฎ heuristic อย่างง่าย (ความสูงตัวอักษร + ระยะห่างบรรทัด)
  ซึ่งเพียงพอสำหรับสาธิต แต่เอกสารที่มีรูปแบบซับซ้อนมากอาจต้องปรับค่าพารามิเตอร์

## การทดสอบระบบ

ไฟล์ `sample_data/test_page.png` เป็นภาพเอกสารไทย 2 คอลัมน์พร้อม header/footer
ที่สร้างขึ้นเพื่อทดสอบว่าระบบตรวจจับคอลัมน์และกรอง header/footer ได้ถูกต้อง
สามารถอัปโหลดไฟล์นี้เข้าแอปเพื่อทดลองใช้งานได้ทันที
